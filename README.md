# Café Hagen — Website Redesign

A modern redesign concept for Café Hagen, a 6-location specialty coffee brand based in Seattle, WA.

## Stack
- Next.js 15 (App Router, TypeScript)
- Tailwind CSS v4
- Framer Motion
- shadcn/ui + Radix UI
- Lucide React

## Getting Started

```bash
npm install
npx shadcn@latest add tabs sheet button badge separator accordion tooltip
npm run dev
```

Open http://localhost:3000

## Project Structure

```
/app          - Next.js App Router pages and layout
/components   - All UI sections (Nav, Hero, Locations, Menu, etc.)
/components/ui - shadcn component library
/lib          - Utilities (cn helper)
/public       - Static assets
```
